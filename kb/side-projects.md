# Side projects on GitHub

Dillon's public GitHub profile is github.com/dillon-shearer. Besides this site's own repository (ds-portfolio), these public projects are there.

## Kanban95

A Windows 95-styled desktop kanban board that runs AI coding agents. The user writes tickets, presses Run, and the board starts Claude Code or Codex CLI for each ticket in its own copy of the repository. A second agent tests the work against the ticket's acceptance criteria, failures are retried, and passing work is merged. It only calls the user when it is stuck. It runs on Windows and Mac and is written in TypeScript.

## DWD Document Skill

A document branding skill for Data With Dillon. It gives any AI agent the rules, templates and checkers to produce on-brand Word, PowerPoint, Excel, Markdown and HTML files. It follows the open Agent Skills format and is written in Python. One of the YouTube videos shows AI agents building it.

## Home Board

A DIY wall board. A Raspberry Pi drives a monitor that shows a full screen photo slideshow, and phones on the home network manage the photos through a small admin site. Written in Python with FastAPI.

## Git for researchers demo

A small Python demo repository that draws a volcano plot for differential expression results and counts the genes that pass a p-value cutoff.
