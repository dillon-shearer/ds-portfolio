# Site pages and navigation

The main menu has five items: Home, About, Demos, Videos and Contact.

| Page | Path | What it holds |
|---|---|---|
| Home | / | Start page with Dillon's name, a short intro, links to Demos, Resume and Contact, and the latest video. |
| About | /about | Bio, current work at Answer ALS, resume links and certifications. |
| Resume | /resume | The full resume as HTML, with a PDF download. |
| Demos | /demos | Projects to open or read about: the Gym Tracker, the Variant Report Tool and the site chatbot. |
| Gym Tracker | /demos/gym | The live gym dashboard with analytics, a 3D body map and an AI coach chat. |
| Gym Tracker case study | /work/gym-tracker | How the Gym Tracker AI chat queries Postgres safely. |
| Videos | /videos | Videos from the Data With Dillon YouTube channel, newest first. |
| Site notes | /colophon | How the site is built and deployed. |
| Contact | /contact | Contact form, email and social links. |

The footer repeats the menu and links to GitHub, LinkedIn, the site email and the source code.
